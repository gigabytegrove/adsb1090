# Contributing

Thanks for helping improve this project.

Before making a change, review the README and existing issues. Keep changes focused, preserve existing behavior unless the change intentionally modifies it, and include documentation when user-facing behavior changes.

For code changes:
1. Create a focused branch.
2. Follow the existing project structure and conventions.
3. Test the affected behavior locally.
4. Update documentation and the changelog when appropriate.
5. Open a pull request describing what changed, why, how it was tested, and any compatibility impact.

Do not commit credentials, tokens, private keys, local configuration, generated secrets, or personal data.
